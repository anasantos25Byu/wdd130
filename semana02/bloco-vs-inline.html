Exercício: Elementos de Bloco vs. Em Linha

Alguns estilos básicos foram aplicados para ilustrar a estrutura e os limites dos elementos.

Tarefa 1: Trocar Elementos de Bloco e Em Linha

No HTML deste documento, este elemento div foi alterado para um elemento span.

O que acontece com o layout? Ele ainda ocupa toda a largura?

Resposta: Não. O elemento span é inline (em linha), então ele ocupa apenas o espaço do conteúdo. Diferente do div, ele não quebra a linha automaticamente nem ocupa toda a largura da página.

Tarefa 2: Aninhando Em Linha em Bloco

Um elemento de parágrafo <p> (bloco) com um elemento <span>, além de um elemento <strong> e um elemento <em>.

Adicione outro elemento inline como <em> ou <strong> dentro do parágrafo. Observe como ele flui dentro da linha.

Resposta: Os elementos inline ficam na mesma linha do texto e acompanham o fluxo normal do conteúdo.

Tarefa 3: Aninhando Bloco em Em Linha

Tentativa de colocar um elemento de bloco dentro de um span:
Este é um elemento div dentro de um span.

Que erro ou problema de layout você vê? Por que isso acontece?

Resposta: O layout pode ficar quebrado ou inválido, porque o elemento span é inline e não deve conter elementos de bloco como div. O HTML considera isso uma estrutura incorreta.

Tarefa 4: Revise a marcação HTML dos seguintes Elementos Em Linha

Elemento de imagem <img>



elemento de âncora <a>

Resposta: Os elementos img, a e button são elementos inline ou inline-block, então podem aparecer lado a lado sem ocupar toda a largura da página.
